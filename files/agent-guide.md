# AIエージェント向け手順書：Vrewの字幕を直して Premiere に戻す仕組みを作る

> この手順書は AIエージェント（Claude Code / Codex など）が読むためのものです。ユーザーと会話しながら、上から順に進めてください。
> 配布元：https://ryoya9595.github.io/vrew-telop-fix-manual/
> ユーザーから配布元ページのURLだけを渡された場合も、この手順書に従って進めてください。

## 1. ゴール

ユーザーのPCに、**Vrew で作った字幕の誤字をAIが直して、Premiere Pro に読み込める字幕ファイル（SRT）として返す**仕組みを作る。最後に、**ユーザーの実際の字幕1本で「直す → 確認 → Premiere に読み込む」まで通す**。

完成した仕組みの流れ：

```
Vrew で字幕を書き出す（SRT）→ AIが誤字だけ直す → srt_check.py でタイムコードを確認
→ 変更一覧をユーザーが確認 → Premiere に読み込む
```

直すもの：誤変換・誤字脱字、固有名詞（人名・商品名・ツール名）、数字や単位の表記ゆれ
直さないもの：**タイムコード・字幕の枚数・字幕の切れ目**、話し方や言い回し（言っていない言葉を足さない）、テロップの色や位置などの見た目

## 2. 守ること

- **インストール・設定の変更の前に、何をするかを説明してユーザーの了承を取る**
- **元の字幕ファイルは上書きしない。** 直したものは `<元の名前>_fixed.srt` として同じフォルダに保存する
- **タイムコード（`00:00:01,000 --> 00:00:03,200` の行）と番号の行は1文字も変えない。** 字幕を足す・消す・つなげる・分けることもしない
- 1枚の字幕の中の改行位置も、原則そのままにする（Premiere での見え方が変わるため）
- 意味が2通りに読める・聞き取りが怪しい所は勝手に決めず、**「要確認」として変更一覧に残してユーザーに聞く**
- 直したら必ず `srt_check.py` を実行し、✅ が出るまで Premiere に読み込ませない
- `.env` や認証情報のファイルは読まない
- 最初の動作確認は **短い動画（1〜3分）の字幕** で行う
- 「できた」と言う前に「7. 動作確認チェックリスト」を実際に確認する
- Windows を前提に書いている。Mac の場合は読み替える（`python` → `python3`、パス区切り、`%USERPROFILE%` → `~`）

## 3. 仕組み

```
%USERPROFILE%\telop-fix\          ← 仕組みの置き場（1つだけ作る）
  srt_check.py                    ← タイムコード確認スクリプト（配布元からダウンロード）
  用語集.txt                       ← 固有名詞・表記ルール（使うほど育てる）
  クライアント別\<クライアント名>.txt ← クライアントごとの表記ルール（あれば）
  記録.csv                         ← 1本ごとの作業時間の記録（前後比較用）

動画ごとのフォルダ\
  <名前>.srt                       ← Vrew から書き出した元の字幕（触らない）
  <名前>_fixed.srt                 ← AIが直した字幕（Premiere に読み込むのはこれ）
  <名前>_fixed_変更一覧.txt         ← srt_check.py が作る。ユーザーが目で確認する
```

判断の理由（変えるときはこの理由を踏まえること）：
- **SRTで往復させる。** Premiere をAIに直接操作させる方法は、バージョンによって指示が無視されることがあり不安定。SRTはテキストなので、AIが確実に読んで直せる
- **タイムコードはスクリプトで機械的に確認する。** AIが文字を直すときに、時間の行や空行を崩すことがある。目で見ても気づきにくいので、元と直した後を比べて1文字でも違えば止める
- **用語集を育てる。** 同じ固有名詞の変換ミスは毎回起きる。ユーザーが直した言葉を用語集に足していけば、2本目から手直しが減る

## 4. フェーズA：今のやり方を聞く（最初に必ず）

ユーザーに次を聞く。答えによって進め方が変わる。

1. **Vrew の字幕を、Premiere にどうやって持っていっているか**
   - (a) Vrew から字幕ファイル（.srt）を書き出して、Premiere に読み込んでいる → このまま進める
   - (b) Vrew から Premiere 用のプロジェクト（XML）で書き出している → Premiere 上で字幕が「キャプション」として入っているか、「テキスト（グラフィック）」として入っているかを確認してもらう
     - キャプションなら：Premiere の「テキスト」パネル → 「キャプション」タブ → メニュー（…）から **SRTとして書き出し** → それを直して読み込み直す
     - テキスト（グラフィック）なら：SRTの往復は使えない。**Vrew の段階で SRT を書き出して直す → 直した字幕を Premiere のキャプションとして入れ、見た目はトラックスタイルで一括指定する**やり方に切り替えることを提案する（ユーザーの了承を取る）
   - (c) わからない → 画面を見て一緒に確認する
2. **Premiere のバージョン**（ヘルプ → Premiere Pro について）。メニューの名前はバージョンで少し違うので、案内するときは画面で確かめてもらう
3. **よく出る固有名詞**（クライアント名・商品名・人名・ツール名）と、表記のルール（例：「Instagram」か「インスタ」か、数字は半角か）
4. **台本や原稿があるか**（あれば照らし合わせると精度が上がる）
5. **今、1本の誤字直しに何分かかっているか**（前後比較のため `記録.csv` に残す）

## 5. フェーズB：置き場を作る

1. `%USERPROFILE%\telop-fix\` を作る（作る前に了承を取る）
2. `srt_check.py` を配布元からダウンロードして置く
   - URL：https://ryoya9595.github.io/vrew-telop-fix-manual/files/srt_check.py
3. Python が入っているか確認する（`python --version`）。無ければ入れ方を案内する（入れる前に了承を取る）
4. `用語集.txt` を作り、フェーズAで聞いた固有名詞と表記ルールを書く。書き方は配布元の `glossary_sample.txt` を参考にする
   - URL：https://ryoya9595.github.io/vrew-telop-fix-manual/files/glossary_sample.txt
5. `記録.csv` を作る（列：日付, 動画名, 字幕の枚数, AIを使う前の分数, 使った後の分数, メモ）

## 6. フェーズC：スキル（いつもの手順）を作る

ユーザーが次から「この字幕を直して：<ファイルの場所>」と言うだけで動くように、手順を保存する。

- **Claude Code の場合**：`%USERPROFILE%\.claude\skills\telop-fix\SKILL.md` に保存する
- **Codex の場合**：`%USERPROFILE%\telop-fix\AGENTS.md` に保存し、字幕を直すときはこのフォルダで Codex を開いてもらう
- 中身は配布元の `SKILL_template.md` をもとに、フェーズAの答え（持っていき方・用語集の場所・クライアント別ルール）を書き込む
  - URL：https://ryoya9595.github.io/vrew-telop-fix-manual/files/SKILL_template.md

## 7. フェーズD：実際の字幕1本で動作確認

ユーザーに、短い動画の字幕（SRT）を1つ選んでもらい、次を全部確認する。

- [ ] 元の `.srt` が変わっていない（更新日時が同じ）
- [ ] `<名前>_fixed.srt` ができている
- [ ] `python srt_check.py 元.srt 元_fixed.srt --normalize` で ✅ が出た
- [ ] `_変更一覧.txt` をユーザーと一緒に見て、直し方に納得してもらえた（要確認の所は答えをもらって反映した）
- [ ] ユーザーが Premiere に `_fixed.srt` を読み込み、タイムラインに置いて、字幕のタイミングがずれていないことを目で確認した
  - 読み込み方の目安：ファイル → 読み込み → `_fixed.srt` を選ぶ → プロジェクトパネルからタイムラインへドラッグ（キャプショントラックになる）
  - 見た目は、キャプショントラックに「トラックスタイル」を作って一括で当てる（1枚ずつ直さない）
- [ ] ユーザーが直した言葉があれば `用語集.txt` に足した
- [ ] `記録.csv` に今回の時間を書いた

全部 ✅ になったら、「次からは『この字幕を直して：<場所>』と言えば動きます」と伝えて終わる。

## 8. 困ったとき

| 症状 | 原因と対処 |
|---|---|
| srt_check.py で「タイムコードが変わっている」 | AIが時間の行を触った。`_fixed.srt` を作り直す（元の時間の行をそのまま写し、文字の行だけ差し替える） |
| srt_check.py で「枚数が違う」 | 字幕をつなげた・消した・空行が崩れた。作り直す |
| Premiere で日本語が文字化けする | `--normalize` を付けて保存し直す（元と同じ文字コードにする）。それでもダメなら UTF-8（BOMあり）で保存する |
| Premiere に読み込むと字幕が全部ずれる | 元のSRTの時点でずれている（Vrew側）か、シーケンスのフレームレートが違う。元の `.srt` を読み込んでもずれるか確かめて切り分ける |
| 字幕の見た目（色・フチ）が消えた | SRTには見た目の情報がない。キャプショントラックの「トラックスタイル」で一括指定する |
| 固有名詞が毎回まちがう | `用語集.txt` に「まちがい → 正しい」の形で足す |
